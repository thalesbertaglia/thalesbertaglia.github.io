# Previous website

The former al-folio website was removed from the working tree after the local cutover. The `previous-site/` path is ignored so an accidental local copy cannot be committed again.

Generated `_site` output and local Jekyll caches are not archived. The legacy `gh-pages` SSH key pair is also deliberately omitted because a private key must not be preserved in the repository.

The active, self-contained website now lives at the repository root.
